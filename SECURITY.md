# Security Policy

## Reporting a vulnerability
**Do not open a public issue for security problems.**

Report vulnerabilities privately via GitHub's **"Report a vulnerability"** button
in the affected repository's **Security** tab (private vulnerability reporting), or
email **alvaro.gomezgil91@gmail.com**.

Please include:
- Affected repository, component and version/commit
- Steps to reproduce or a proof of concept
- Impact as you understand it

## What to expect
- Acknowledgement within **3 business days**
- An initial assessment within **10 business days**
- Coordinated disclosure once a fix is available

## Supported versions
Only the latest release of each repository receives security fixes unless stated otherwise.
