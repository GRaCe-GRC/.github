# Code of Conduct

We want GRaCe-GRC to be a welcoming, harassment-free space for everyone.

## Expected behavior
- Be respectful and assume good intent.
- Give and accept constructive feedback gracefully.
- Focus on what is best for the project and the people in it.

## Unacceptable behavior
- Harassment, insults, or discriminatory language or imagery.
- Personal or political attacks, trolling, or deliberate disruption.
- Sharing others' private information without permission.

## Enforcement
Report concerns to **alvaro.gomezgil91@gmail.com**. Maintainers will review reports
promptly and confidentially, and may remove content or contributors that violate
this code.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).
